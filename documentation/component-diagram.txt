Component Diagram Analysis
=====================================================

## Explanation
The Component Diagram showcases the modular structure of the Next.js application. It breaks down the system into the Presentation Layer (UI Components and Pages), the API Layer (Next.js Routes acting as backend controllers), the Service Layer (authentication and database utilities), and the Data Layer (external services and databases). 

## Related Files
- `components/Navbar.tsx`
- `components/DocumentationCarousel.tsx`
- `app/api/*`
- `lib/auth.ts`
- `lib/prisma.ts`

## Inferred Actors/Entities/Components
- UI Components: Global UI elements used across pages.
- Client Pages / Server Pages: The actual route views.
- Auth Module: Handles JWT logic.
- API Controllers: The Request handlers in `app/api`.
- Database Access (Prisma).

## Relationships
- Pages utilize UI Components.
- Client-side Pages/Components call API Controllers via HTTP.
- Server-side Pages query Database Access directly.
- API Controllers depend on Auth Module and Database Access.

        Postgres[(PostgreSQL)]

    Pages --> UI

    Pages -.->|HTTP Fetch| AuthAPI

    AuthAPI --> AuthSvc
    ArticleAPI --> AuthSvc
    DocAPI --> AuthSvc

    ArticleAPI --> UploadSvc
    DocAPI --> UploadSvc

    AuthAPI --> DBClient
