API Flow Analysis
=====================================================

## Explanation
The backend logic is entirely encapsulated within Next.js Route Handlers (`app/api/*`). The API exposes endpoints for Authentication, Article Management, Documentation Management, and Media Uploads.

## Inferred CRUD Operations & Data Fetching Patterns
- `/api/login` (POST): Authenticates admin, compares bcrypt hashes, returns JWT.
- `/api/articles` (GET, POST): Fetches all articles or creates a new one. POST requires a valid JWT extracted from the `Authorization: Bearer <token>` header.
- `/api/articles/[slug]` (GET, PUT, DELETE): Manages specific articles based on slug. Mutations require JWT.
- `/api/documentations` (GET, POST): Similar to articles, manages event galleries.
- `/api/documentations/[slug]` (GET, PUT, DELETE): Manages specific documentations.
- `/api/upload` (POST): Handles multipart/form-data. Interacts with Supabase to store images and returns public URLs.

## Related Files
- `app/api/login/route.ts`
- `app/api/articles/route.ts`
- `app/api/articles/[slug]/route.ts`
- `app/api/upload/route.ts`

## Relationships
- Protected routes validate requests using the `verifyToken` function from `lib/auth.ts`.
- All routes interact directly with PostgreSQL via `prisma`.
